# Library FAQ Accordion (React + Vite)

```bash
npm install
npm run dev      # start dev server
npm run build    # production build
```

Structure:

- `src/components/Accordion/` – reusable Accordion (`Accordion`, `AccordionItem`, `useOpenIds`)
- `src/components/OptionsPanel.jsx` – demo options panel
- `src/data/faqItems.js` – FAQ data
- `src/App.jsx` – demo page
